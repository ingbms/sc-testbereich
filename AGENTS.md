# sc-testbereich

Eigenständige Testkopie von Smiling Relations. Einstieg und Pflegehinweise: `README.md`.

- Astro, statische Ausgabe, GitHub Pages, Deutsch. Design und Inhalte sind aus der genehmigten Ausgangswebsite übernommen.
- Dieses Repository unabhängig bearbeiten; Änderungen werden nicht automatisch in `HP-SmilingRelations` übertragen.
- Tabellen für Termine und Stimmen sind mit der Ausgangswebsite geteilt und nur lesend angebunden. Keine Google-Inhalte ohne ausdrücklichen Auftrag ändern.
- Medien ausschließlich aus den vorhandenen Quellen; `nomedia` rekursiv ausschließen. Originale nicht überschreiben. Lokale freie Schriften samt Lizenzen erhalten.
- Kein generiertes Ersatzportrait verwenden; neue Profilfotos stehen weiterhin aus.
- Besucherstatistik deaktiviert lassen. Keine Zugangsdaten einchecken.
- `noindex, nofollow` auf allen Testseiten erhalten. GitHub-Pages-Unterpfad `/sc-testbereich` bei Prüfungen berücksichtigen.
- Änderungen mit `npm run check`, `npm test` und `npm run build` prüfen; bei Links, Layout oder Interaktionen passende Browserprüfungen ergänzen.
- Nutzerkommunikation auf Deutsch. Aktuellen Arbeitsstand in `documentation/PROJECT_STATE.md` festhalten.
